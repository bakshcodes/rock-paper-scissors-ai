# 🎮 Rock, Paper, Scissors AI

## About

A Python game where the player competes against a computer. The computer uses move history and patterns to predict the player's next move.

## Features

* Play Rock, Paper, Scissors.
* Track player and computer scores.
* Store move history using dictionaries.
* Predict player moves using patterns.

## Technologies

* Python
* Git and GitHub
* Tkinter (planned for the GUI)

## How to Run

1. Download or clone the repository.
2. Open the Python file in Thonny.
3. Click **Run** and follow the prompts.

## What I'm Learning

Python programming, basic AI concepts, pattern recognition, and Git version control.
